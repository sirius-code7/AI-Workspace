# AI Workspace

Interface Web d'une plateforme d'Intelligence Artificielle développée en **HTML**, **CSS** et **JavaScript**.

Ce projet est réalisé dans le cadre d'un atelier **Technos Web pour IA**. L'objectif est de construire graduellement une interface (IHM) utilisateur capable d'interagir, dans un premier temps, avec des services d'IA simulés en JavaScript, puis avec de véritables API d'IA.

## Objectifs

* Construire une interface Web moderne.
* Bonnes pratiques HTML, CSS et JavaScript.
* Simuler plusieurs services d'Intelligence Artificielle.
* Préparer une architecture facilement connectable à des API réelles.

## Fonctionnalités

* Structure HTML de l'AI Workspace
* Design responsive avec CSS
* Résumé de texte (simulation)
* Traduction (simulation)
* Chat IA (simulation)
* Prédiction (simulation)
* Historique des requêtes avec stockage local
